# WhoUsesPreventiveCare

## 🏥 Description

In this project I examine patterns that are in the preventive healthcare utilization using a dataset that I cretaed. I wanted to learn and find which groups are more or less likely to use preventive care. I wanted to focus on using the rates to see compare the groups

## 📖 What am I learning
In this project I will be learning:
- Compare groups using proportions
- Looking for strong and weak patterns
- Creating a df
- Crosstab Analysis
- Barchart Analysis

## 🔢 Data Description
Each row in the dataset represents a patient that either uses preventive care or not

- **age_group** : Age category (18–34, 35–49, 50–64, 65+)
  - **sex** : Female or Male
  - **insurance** : Private, Public, or Uninsured
  - **preventive_visit** : Indicates whether the individual had a preventive care visit (Yes/No)

## 📈 Analysis Approach
To be able to compare the utilization among the different groups for preventive care I used their rates.

1. Found the baseline of preventive care usage
2. Compared the rates across the insurance groups
3. Compared the rates across the age age groups
4. Stratified analysis focusing on (50-64) age group

## Summary
This finding does have some limitations due to the data being synthetic, but the main idea is that I was able to find that their insurance showed a stronger association with the preventive care usage. As individuals with private insurance were more likely to report the preventive care. Then the stratfied finding would suggest that even the age group the utilization would persist.
